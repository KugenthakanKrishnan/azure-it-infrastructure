# azure-it-infrastructure
Enterprise IT Infrastructure deployment using Microsoft Azure, Windows Server, Active Directory, Linux and Azure Monitor

Technologies Used
- Microsoft Azure
- Windows Server
- Active Directory
- Linux (Ubuntu)
- Virtual Networks and VNet Peering
- Network Security Groups (NSGs)
- RBAC (Role Based Access Control)
- Azure Monitor

Architecture
- Two Virtual Networks with VNet Peering
- Windows Server VM with Active Directory
- Linux VM for administration
- NSG rules controlling all traffic
- RBAC access control
- Azure Monitor alerts for CPU and Memory
